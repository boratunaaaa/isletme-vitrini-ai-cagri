## Çalışma Kuralları

- Önce mevcut klasörü analiz et.
- Kullanıcı onayı olmadan dosya silme.
- Büyük değişikliklerden önce kısa plan çıkar.
- Mevcut çalışan sistemi bozma.
- .env, API key, token, credentials, şifre dosyalarına dikkat et.
- İş sonunda PROJECT_STATUS.md, CHANGELOG.md ve TODO.md dosyalarını güncelle.
- Genel önemli bilgileri ~/AI_MEMORY/GLOBAL_STATUS.md dosyasına yaz.
